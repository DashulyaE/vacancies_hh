# Приложение для поиска вакансий на сайте hh.ru
## Описание проекта:
Данное приложение используется для поиска вакансий на сайте hh.ru 
по запросу пользователя по ключевому слову.

Принцип работы:
- Запускается программа, которая предлагает пользователю ввести 
ключевое слово для поиска на hh.ru
- Затем пользователем вводится количество вакансий, с которыми будет осущетсвляться 
дальнейшая работа. Сначала весь список сортируется по размеру заработной платы
и далее из него остается топ N вакансий. 
- Далее вводится ключевое слово, по которому будут отобраны подходящие вакансии
из отобранных на прошлом шаге.
- Пользователю в консоль выводятся оставшиеся вакансии после всех фильтраций.
- Программа предлагает записать эти вакансии в JSON файл. При записи в файл 
происходит проверка добавляемых вакансий на дубли. Если такая уже была, то
вакансия не будет добавлена.
- По желанию пользователя из файла можно удалять записи, введя ID вакансии.

## Реализованы задачи проекта:
1. В модуле *src/head_hunter_api* созданы классы: 
   1. *HeadHunterAPI* для работы с hh.ru, 
в котором реализованы: 
      - метод подключения к API: *_connect*:
      - метод получения данных по ключевому слову: *get_vacancies* 
   2. *BaseApi* - абстрактный класс для работы с API, абстрактные методы *_connect*
   и *get_vacancies*
2. В модуле *src/filehandler* созданы классы:
   1. *JSONSaver* для работы с JSON файлом, 
   в котором реализованы: 
      - метод загрузки данных из JSON-файла: *load_vacancy*:
      - приватный метод сохранения данных в JSON-файл.: *_save_vacancy*
      - метод добавления новых вакансий в JSON файл и его сохранение *add_vacancy*
      - метод для удаления вакансий из файла *delete_vacancy*
   2. *BaseSaver* - абстрактный класс для работы с файлами, абстрактные методы *load_vacancy*, 
*_save_vacancy*, *add_vacancy*, *delete_vacancy*
3. В модуле *src/vacancy* создан класс *Vacancy*, который осуществляет операции с вакансиями. Создает экземпляр класса.
Содержит методы валидации *_validate_name* и *_validate_url* и использует магические методы 
для сравнения экземляров класса по зарплате.
4. В модуле *src/utils* реализованы вспомогательные функции для работы с вакансиями,
получеными с hh.ru:
   - *sorted_vacancies* - сортирует и выдает топ вакансий по размеру зарплаты:
   - *find_vacancies* - возвращает список вакансий, содержащих ключевое слово, 
   - *vacancies_to_obj* - возвращает экземляр класса в определенной структуре.
5. В модуле *main.py* реализована основная функция взаимодействия с пользователем, 
которая объединяет всю логику проекта.

## Инструкция по работе с программой:
- После скачивания проекта в свой репозиторий, установить необходимые библиотеки и зависимости.
- Откройте модуль *src/main*, запустите программный код и введите необходимые данные, следуя
указаниям программы.
- В случае, если данные будут внесены не в том формате, программа выдаст об этом информацию.
- Информация, возвращаемая основными функциями, представлена JSON-файлом и в консоли.

## Тестирование программы ##
В программе реализованы функции тестирования для модулей *head_hunter_api.py, filehandler.py, vacancy.py*
Все тесты расположены в папке *tests*, с названиями *tests_имя тестируемого модуля*

Запуск тестов осуществляется через терминал.

Результаты выполнения тестирования можно посмотреть, выполнив команду в терминале:
```
pytest --cov
```

*htmlcov / index.html*
